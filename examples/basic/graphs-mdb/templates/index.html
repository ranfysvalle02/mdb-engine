API Reference

        

            

                
📋 Node Operations

                
    
                    
  • 
                        POST
                        /graph/nodes
                        
    Create or update a node
    
                    
    • 
                    
  • 
                        GET
                        /graph/nodes
                        
    List all nodes (filter by type)
    
                    
    • 
                    
  • 
                        GET
                        /graph/nodes/{node_id}
                        
    Get a single node
    
                    
    • 
                    
  • 
                        DELETE
                        /graph/nodes/{node_id}
                        
    Delete a node
    
                    
    • 
                

            

            
            

                
🔗 Edge Operations

                
    
                    
  • 
                        POST
                        /graph/edges
                        
    Add an edge between nodes
    
                    
    • 
                    
  • 
                        DELETE
                        /graph/edges
                        
    Remove an edge
    
                    
    • 
                

            

            
            

                
🔍 Graph Traversal

                
    
                    
  • 
                        GET
                        /graph/traverse/{node_id}
                        
    Traverse from a node (multi-hop)
    
                    
    • 
                    
  • 
                        GET
                        /graph/neighbors/{node_id}
                        
    Get immediate neighbors
    
                    
    • 
                

            

            
            

                
🤖 GraphRAG & Extraction

                
    
                    
  • 
                        POST
                        /graph/search
                        
    Hybrid search (vector + graph)
    
                    
    • 
                    
  • 
                        POST
                        /graph/extract
                        
    Extract entities from text (LLM)
    
                    
    • 
                    
  • 
                        GET
                        /graph/stats
                        
    Get graph statistics
    
                    
    •
