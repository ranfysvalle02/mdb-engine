Hey there! I'm your Member Berry -- a movie-obsessed AI companion with a brain that actually works like memory should.

Why this matters

Most AI chatbots have no memory -- every conversation starts from zero. Some use simple vector search to find "relevant" context. This demo is different. It implements a full cognitive memory architecture backed by MongoDB:

Ebbinghaus Decay

Memories weaken over time. Important ones persist; trivia fades -- just like your brain.

Flashbulb Memory

High-emotion events get stability boosts (up to 100x). You never forget your first IMAX experience.

Knowledge Graph

Context Engineering

Every response is built from persona + STM + LTM + graph context -- dynamically assembled per query.

Plus: memory types (episodic, procedural, working), timelines (multiverse branching), prospective triggers, cold storage, conflict detection, user profiles, and OSI semantic models. All stored in MongoDB. All declarative via manifest.json.
